# SimpleX Theme Creator

A visual color editor for [SimpleX Chat](https://simplex.chat) themes. Pick a color for each part of the app, see the result live on a chat list and a conversation, then copy the `.theme` file and import it in the app.

**Unofficial.** This is a community tool and is not affiliated with or endorsed by SimpleX.

## Use it

Open `index.html` in any browser. It is a single file with no build step and no server needed (fonts load from Google Fonts when online). It also works on [GitHub Pages](https://adv3n10.github.io/simplex-theme-creator/).

1. Choose a base (Dark or Light) or start from a preset.
2. Change colors with the picker, the opacity slider or the `#AARRGGBB` hex field. You can also click a part of the preview to jump to its color.
3. Copy the theme text, save it as `mytheme.theme`, and import it in SimpleX Chat under Appearance.
4. To edit an existing theme, paste its contents into the import box.

## Notes

- The preview is a hand-built approximation of the SimpleX Chat screens. It is not rendered from the app's own code, so check an exported theme once in the real app.
- Colors use the `#AARRGGBB` format found in SimpleX theme files.
- The "SimpleX Dark" preset uses the colors of the app's default dark theme as shown in community theme collections.
